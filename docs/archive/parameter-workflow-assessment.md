# 参数功能评估与完善

> 历史评估记录：保留当时的基线、发现和验证结果。当前版本说明见[文档索引](../README.md)与[更新记录](../../CHANGELOG.md)。

日期：2026-11-17。范围：Query、Path、Headers、form-data、URL 编码表单，从编辑、保存状态到请求组装。沿用现有 IPC 和工作区文件格式，未增加依赖。

## 本轮修复

| 问题 | 修复后的行为 |
| --- | --- |
| 新增行只在失焦时提交，快捷键发送可能漏掉当前参数 | 首个输入原子新增完整行，后续输入直接更新请求；复用输入框保持焦点 |
| 清空单元格会隐式删除参数 | 保留空行，使用显式删除操作移除；启停、说明和顺序继续保留 |
| 输入通用 Header 名称后编辑行立即隐藏 | 当前编辑行保持可见，用户主动隐藏通用 Header 或切换请求后恢复筛选 |
| 批量编辑重建行，丢失说明和 secret 标记 | 原样内容不触发写入；编辑后按内容、同名出现顺序、值和位置保留元数据。无法确认身份时保守保留敏感标记 |
| 带冒号的参数名、首尾空格、多行值无法可靠往返 | 保留主线的四列 quoted TSV、Query String 和 URL 查询导入；格式错误逐行展示并保留编辑草稿 |
| form-data 的新增类型选择与草稿分离 | 选择文件类型只新增一行；文件选择返回后验证原行/组件仍有效，失败进入统一错误展示 |
| 切换两种表单格式清空参数 | 文本行及元数据保留；包含文件时阻止转成 URL 编码表单，提示先移除文件或明确改为文本 |
| 表单类型选项在窄请求面板溢出 | 允许选项换行，类型、说明列按实际表格顺序对齐 |
| Path 识别扫描了主机、用户信息 | 仅扫描路径，排除 Query、fragment 和字面量中的冒号；切换相同 URL 的请求也各自同步 |
| Path 行可改名/删除，与地址栏占位符脱节 | 名称由地址栏维护、表格只读，仍可修改值、说明和启用状态 |
| `:id` 替换污染 `:id2`、Query 或用户信息 | Rust 按完整占位符匹配，只替换路径；保留现有斜杠编码规则 |
| Query/API Key 拼到 `#fragment` 后面，没有实际发出 | 在 fragment 前追加，正确处理已有 `?`、尾部 `&`、重复键和百分号编码 |
| Sortable 已移动 DOM 后 Vue 再按旧索引渲染 | 先恢复原 DOM 顺序，再应用数据重排 |

Path 语法保持当前已落地的 `:id`、`{id}`、`{{id}}`；冒号形式仅在路径段开头识别。URL 中双花括号继续表示 Path 参数，参数值内仍可引用环境变量。本轮未把 URL 改为环境变量模板。

## 后续优先项

1. **URL 与 Query 表格联动**：主线已支持向新增行粘贴 Query String 或完整 URL 的查询部分；地址栏与 Query 表格仍未双向同步，需要先明确重复键、空值、原始编码、禁用行和签名 URL 的保真规则。
2. **继承 Header 的独立展示与覆盖**：当前通用 Header 筛选不等于集合/文件夹继承来源展示；需与继承解析数据一起设计。
3. **超过 50 行的虚拟列表**：当前仍全量渲染，需与输入焦点、拖拽和键盘排序一并验证。
4. **跨 Body 类型的草稿恢复**：本轮仅保留两种表单格式互转；切到 none、JSON、binary 等类型仍沿用现有替换行为。
5. **文件参数信息**：文件名/大小预览、失效文件提示仍待完善。
