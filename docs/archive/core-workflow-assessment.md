# 核心请求与工作区流程评估

> 历史评估记录：保留当时的基线、发现和验证结果。当前版本说明见[文档索引](../README.md)与[更新记录](../../CHANGELOG.md)。

评估日期：2026-11-17。范围是请求编辑、保存、发送、取消及工作区关闭/切换，依据产品与交互设计、现有实现和回归验证；不是全产品功能验收。

现有实现已串起日常请求和本地工作区流程。本轮优先处理会丢失编辑、误发请求或显示错误保存状态的问题，并补齐实际可操作的取消入口。

## 已完成

| 流程 | 原有问题 | 完善后的行为 |
| --- | --- | --- |
| 环境编辑与保存 | 保存返回的旧快照覆盖期间的新编辑；编辑器、发送和关闭可同时写同一环境 | 共用在途保存任务，保留新编辑并继续写入，全部确认后才清除未保存标记 |
| 请求自动/手动保存 | 多次保存可交错完成；较旧保存成功会清除新编辑的标记 | 按标签顺序保存，比较持久化字段，只确认实际落盘的内容 |
| 预览标签 | 编辑后仍保持预览身份，打开另一个预览会替换内容 | 编辑后自动固定；发送时也固定，防止响应落到被复用的预览标签 |
| 保存失败与关闭 | 自动保存只输出控制台；关闭标签不等待落盘，失败后内容已被移除 | 显示统一错误反馈；已绑定请求的标签保存失败时保留；工作区关闭/切换等待保存并显示具体错误 |
| 请求准备与取消 | 加载工作区期间可重复发送；保存环境期间取消无效；迟到句柄/报错影响下一次请求 | 从准备阶段锁定发送状态及原会话；取消废弃旧异步续体，迟到句柄补发取消，旧错误不改写新请求 |
| 取消入口 | URL 栏发送期间仅显示禁用按钮，未连接已有的取消方法 | 发送中显示可点击的“取消”；Esc 同样取消，已打开的弹层优先处理键盘事件 |
| 请求完成 | 请求成功直接清除未保存标记，包括尚未落盘的草稿 | 响应只更新运行结果；未保存标记由保存流程管理 |
| 工作区隔离 | 旧加载、保存及排队的环境选择可能在重开后更新新会话 | 这些异步流程检查会话与代次，废弃旧结果并保留新会话的加载状态 |

实现集中在 `src/stores/{request,tabs,workspace,app}.ts`、`UrlBar.vue` 和 `AppBody.vue`。沿用统一 IPC、浅响应对象和有界 orphan 事件缓存，未新增依赖、IPC 字段或工作区文件格式。

## 首屏体积与后续优先级

对生产构建 manifest 从入口沿静态 imports 收集 JS/CSS，逐文件使用 gzip level 9 求和：

- 本轮版本：264,863 字节，约 258.7 KiB。
- 对照版本：263,741 字节，约 257.6 KiB。对照构建仅将本轮修改的六个产品源码文件替换为 Git HEAD 内容，输出到临时目录，保留其他工作区输入。
- 增量：1,122 字节，约 1.1 KiB；两者均超过 150 KiB 预算。本轮产物中的 CodeMirror 未进入首屏。

这是当前生产组合的体积抽查，不替代完整 S5，也未改写历史量测记录。体积预算超限需要单独处理。

| 优先级 | 后续工作 | 依据 |
| --- | --- | --- |
| P1 | 草稿关闭/切换保护与恢复 | 无 `nodeId` 的草稿仍不参与 `tabs.flushAll`，`tabs.close` 也没有草稿保存或放弃选择；本轮保护对象是已绑定集合节点的请求 |
| P1 | 修复首屏静态依赖体积超限 | 对照和本轮构建均超出产品预算，应分析启动依赖与延迟加载边界后再运行完整 S5 |
| P2 | 集合复制下沉 Rust 并检查事务与继承配置完整性 | `workspace.duplicateNode` 仍在前端遍历集合并逐条 IPC，不符合集合规模计算放在 Rust 的约束；本轮未改动复制流程 |
| 验证阻碍 | 恢复 Rust 构建脚本执行能力 | 解除本机拒绝访问原因后，需重跑 Rust 测试、重建 debug 宿主，再执行桌面 E2E |

## 0.1.1 主线集成

发布版本以主线为基线，保留 OAuth2 取消、凭据基线比较与继承来源保护。顺序保存测试同时验证凭据轮换期间的第二次保存使用新基线。

集成后本机验证：17 个前端测试文件、151 项测试通过；TypeScript、生产构建、90 项对比度、Rust 全工作区格式检查、npm 漏洞审计及 npm/Rust 许可门禁通过。以上初次评估中的测试数量、旧宿主 E2E 和体积数据仅属于当时分支，不代表集成后发布产物。发布流水线会重新构建宿主并执行 Rust、Clippy 和桌面 E2E，全部通过后才生成 Release。

后续集成验证：使用本机已有 Rust 1.95 工具链完成 265 项 Rust 测试、全工作区 Clippy 和 debug 桌面构建；重建宿主的桌面 E2E 通过。CI 窄窗口暴露的鼠标坐标问题已通过先将拖拽按钮滚入可见区域修复，1024×700 与默认窗口均通过，仍断言真实 HTTP 发送顺序。原标签保持不变，重新发布时记录独立 E2E 脚本提交。
