# 文档索引

使用说明以[中文 README](../README.zh-CN.md)、[英文 README](../README.md)和[更新记录](../CHANGELOG.md)为准。设计文档包含目标与未交付规划；历史评估保留各自的提交基线、测试数量和限制，不作为当前版本的验收结果。

## 使用与发布

| 文档 | 用途 |
| --- | --- |
| [中文使用说明](../README.zh-CN.md) / [English](../README.md) | 安装、功能、数据边界与源码运行 |
| [更新记录](../CHANGELOG.md) | 按版本查看已交付改动与兼容性说明 |
| [发布指南](release.md) | 版本升级、验证、标签发布、附件和应用内更新 |

软件更新入口位于启动页“软件更新”、**设置 → 关于**及底部状态栏。检查版本后下载，校验通过即可选择“安装并重启”；先处理未保存内容，成功启动安装程序后退出，安装完成重新打开新版。也可手动打开安装包。官方安装包目前仅提供 Windows 10/11 x64。

## 历史评估

评估记录集中在 [archive](archive/README.md)，包含参数、核心工作流及四轮功能复评。文中的“当前”“待修复”、测试数量和源代码行号均属于对应记录的日期与基线；后续修复见更新记录及相关提交。

## 维护约定

- 用户可见变化先更新 `CHANGELOG.md` 的 `Unreleased`，发布时移入带日期的版本段，并同步受影响的中英 README。
- 发布操作与更新协议统一维护在 `release.md`，检查命令以 `.github/workflows/ci.yml` 和 `release.yml` 为准。
- 新评估写明日期、提交基线、实际运行的检查和未验证范围；阶段结束后归档，保留证据。
- 不将规划、历史测试结果或旧性能量测改写为当前版本已通过的承诺。
